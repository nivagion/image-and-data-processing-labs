# Image and Data Processing Labs

This repository consolidates several small educational projects and programming experiments created while learning the underlying concepts.

| Project | Created | Language / Technology | Description |
| --- | --- | --- | --- |
| [Edge Detection](edge-detection/) | [February 2024](https://github.com/nivagion/image-and-data-processing-labs/commit/cd5a045fc0a70b04b73db4c2d7020dc1adeb9c22) | Python, NumPy, OpenCV | Implements grayscale conversion and Sobel edge detection over a sample image. |
| [QR Code](qr-code/) | [February 2024](https://github.com/nivagion/image-and-data-processing-labs/commit/0d57fb884bf3c93585cfd6b10a7a87252dc2460b) | Python, `qrcode`, Pillow | Generates a QR code image from interactively supplied data. |

Each directory preserves the imported project's Git history. Generated images under project `output` directories are intentionally ignored.

## Project Dates and History

The **Created** column records the month and year of each project's first preserved source commit. Each date links directly to that commit in this repository's history. Select a project name to inspect its implementation and its project-level README.
