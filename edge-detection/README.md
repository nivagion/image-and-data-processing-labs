# Edge Detection

This Python project demonstrates manual grayscale conversion and Sobel edge detection over an image loaded with OpenCV. NumPy is used for pixel arrays and convolution-style calculations, and a sample input image is included.

Install NumPy and OpenCV, then run `python Main.py` from the `Edge detection` directory. Select `gs` for grayscale conversion or `so` for Sobel processing; the generated image is written under `output` and is ignored by Git.
